## Note

The numbers in `docs/evidence-base.md` for the sources not present here were extracted from
the publishers' abstracts, full-text HTML, and figure/table captions during research. They
are accurate to what those sources state, but if you are going to lean hard on a specific
figure — particularly the `[BUR11]` daily-intake table or the `[RON14]` effect sizes —
check it against the original.

PDFs are gitignored (see `.gitignore`); this README is not, so the manifest travels with
the repo even though the files do not.
